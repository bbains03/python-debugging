Debugging Methodology

My approach to each debugging exercise follows a structured process:

1. Identify: Run the program and observe errors or unexpected behaviour.
2. Analyze: Investigate the underlying cause of the issue.
3. Resolve: Implement corrections to address the problem.
4. Verify: Test the program to ensure it produces the expected results.
5. Document: Use Git commits to preserve changes and track progress.

Repository Structure

Exercises are organized into directories to maintain a clear record of my learning progression.

Each directory contains Python files corresponding to completed debugging exercises.

Git commit history provides visibility into code modifications, corrections, and improvements over time.
